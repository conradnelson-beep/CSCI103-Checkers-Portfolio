CheckersChampions Portfolio Project
CSCI-103
Spring 2025

Begin the game by typing in ./checkers x y, where x and y are even numbers at least 8 (for generating board dimensions). The first team to take three pieces wins. 
Make a move by typing in the row/column of the piece you want to move, then the row and column of the destination square (eg 2 0 3 1 moves a piece from row 2 column 0 to row 3 col 1).
